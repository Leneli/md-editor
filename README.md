# Markdown Editor

Учебный проект лёгкого редактора исходного Markdown для macOS. Цель — удобно читать и редактировать `.md` и `.markdown`, сохраняя обычные файлы на диске.

Целевая платформа: **macOS 27.0 и новее, только Apple Silicon (`arm64`)**. Среда разработки по требованиям — Xcode совместимой ветки 27.x.

## Текущий этап

Техническое исследование до выбора архитектуры. Изолированный прототип PoC-01 и инструкции сборки, запуска и проверки находятся в [experiments/poc-01-textkit2](experiments/poc-01-textkit2/README.md).

PoC-01 проверяет `NSTextView` + TextKit 2: базовое редактирование, диагностику движка, отзывчивость и память. Подсветка Markdown и сохранение файлов в этот эксперимент не входят. Пригодность движка ещё не установлена: решение требует ручной проверки и замеров на целевом Mac.
