- AppKit-приложение: один NSTextView с TextKit 2, прокрутка, Open UTF-8 только в память,
  стандартные команды редактирования. Автоматические подстановки и исправления отключены.
- Диагностика TextKit 2 и уведомлений fallback, раздельные времена чтения/декодирования/установки.
- App Sandbox с user-selected read-only; ошибки загрузки отделены от оценки движка.
- Генератор семи файлов, независимая проверка и контрольный манифест. Большие файлы исключены из Git.
- XCTest, README опыта, пустой шаблон измерений; обновлена ссылка на PoC в корневом README.

## Замеченные проблемы и ограничения

- Первый запуск `xcodebuild test` из ограниченной среды Codex не получил доступ к
  `com.apple.testmanagerd.control` (Sandbox restriction). После разрешённого запуска вне этой
  среды тесты выполнились. Это ограничение запускающего инструмента, не App Sandbox PoC и не TextKit 2.
- Первый тест частного pasteboard передавал только `.string` и не смог экспортировать выделение.
  Исправлен тест: он запрашивает типы `NSTextView.writablePasteboardTypes`, как предписывает SDK.
  После исправления экспорт/чтение текста прошли без изменения приложения.
- В sandboxed-сборках xcodebuild печатал сообщения недоступности CoreSimulator и файловых сервисов;
  обе macOS-сборки при этом завершились успешно. Есть стандартное предупреждение об отсутствии
  AppIntents для извлечения metadata. Swift-предупреждений в финальных сборках не обнаружено.
- Подключение инструмента просмотра GUI завершилось тайм-аутом. По списку процессов и журналу
  запуск подтверждён, но видимое окно, меню и системный Open Panel визуально не проверены.
- Реальный переход на TextKit 1 намеренно не вызывался; обработчики зарегистрированы, но
  поведение при настоящем системном fallback в этих прогонах не наблюдалось.

  Undo/Redo с клавиатуры, выделение и прокрутка всех размеров и отдельной длинной строки.
- Ввод прямых кавычек, дефисов и остальных последовательностей при включённых системных
  smart quotes/dashes/autocorrection, разные раскладки/IME. Text-input API тест не заменяет эту проверку.
- Open Panel и доступ к реальным файлам в sandboxed-приложении, отмена и ошибки доступа.

- Диагностика при всех ручных действиях, RAM, готовность к взаимодействию, отзывчивость,
  повторные загрузки, три повторения по возможности. Эти показатели не измерены.
